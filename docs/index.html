产品介绍

做电商素材整理，最耗时间的不是选图

而是把图片从页面里一张张抠出来。图提取把这一步压缩成一次点击。

图片散落在页面各处

主图、详情长图、SKU 缩略图混在一起，还夹着图标、logo 和占位图，靠肉眼找既慢又容易漏。

浏览器无法批量保存

右键另存为一次只能存一张，几十张图要重复几十遍操作，命名还得手动整理。

格式不统一，后续还要转

有的 jpg、有的 webp，导入设计工具或上架后台时还要再批量转换一次格式。

核心功能

从扫描到导出，一条链路走完

六个能力覆盖「找得到、看得清、下得齐」。

一键提取

自动扫描页面所有商品图，兼容 srcset、data-src、背景图等多种懒加载写法。

智能过滤

自动排除图标、logo、占位图与小于 100×100 的图片，长宽比异常的也一并跳过。

集中预览

在新标签页用网格展示全部图片，每张显示缩略图与真实尺寸，一眼看清有哪些素材。

自由勾选

支持全选、反选、全不选，也可以按尺寸阈值过滤，只下载你需要的那几张。

统一 PNG

jpg、webp 等格式自动经 canvas 重编码为 PNG，导出即用，不用再转一次。

批量下载

一键保存到浏览器默认下载目录，文件名自动编号为 商品图_001.png。

安装步骤

四步装好，两分钟能用

不需要账号，不需要额外软件，全程在本机完成。

  1. 1

    下载插件压缩包并解压

    从 GitHub Releases 下载 zip，解压到任意本地文件夹（建议路径中不要有中文以外的问题字符）。

  2. 2

    打开 Chrome 扩展管理页

    在地址栏输入 chrome://extensions 并回车。

  3. 3

    打开右上角「开发者模式」

    开关变成蓝色即表示已开启，此时顶部会出现「加载已解压的扩展程序」按钮。

  4. 4

    加载解压后的文件夹

    点击「加载已解压的扩展程序」，选中第 1 步解压出来的文件夹即可。装好后打开任意商品详情页，右下角会出现「获取图片」按钮。

小提示： 如果按钮没出现，先滚动页面让图片加载完再点；插件只在受支持平台的商品详情页注入，其他页面不会显示。
